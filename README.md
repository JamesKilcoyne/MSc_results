# MSc Project Validation and Results
Code used for the results of my MSc project "Near-extremal Kerr Black Holes and EMRI Waveform Modelling For LISA"

This repo has most of the code in Jupyter notebooks. Note that these are only the testing and results of the model built in the Near-extremal emri repo, and so to run these codes, that repo must first be cloned as outlines in the README there. Also the most recent flux and amplitude data (Calculated by Dr. Zachary Nasipak) are not available here, but I can provide them.
